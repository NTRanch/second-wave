# Playtest record — Second Wave v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (seahawk pass on
primo is the scheduled follow-up, see BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped JS realization in demo mode
  rides each level to victory through the continuation path on both
  scenes. Pass = victory with exactly 2 continuations, 0 stops.
- `node tools/conformance.mjs`: JS realization vs C# core vectors,
  exact, 301 trace points per level (903 total).
- `dotnet run --project core/SecondWave.Tests -c Release`: 28 checks,
  validation + adversarial split.
- `node tools/settings-check.mjs`: settings + record bridges
  round-trip and clamp; settings reachable from boot, ungated.
- `node tools/perf.mjs`: step budget.
- Raster-advance audit (estate text law): 108 text ops across all
  screens incl. peak/continuation/demo/end, 0 flagged.
- D-221 visual spot check: frames extracted from the FINAL preview
  MP4s at viewing size and inspected. SHOULD: HUD legible (level,
  scene, phase, depth/target, time, score), the depth gauge with its
  gold peak marker, the concentric figure answering depth, channel
  bars with live values and locked slots named, and in continuation
  the sensitivity meter + held-in-band line. First pass found one
  FAIL (the menu cursor glyph ">" is absent from the raster font and
  rendered as "?"); fixed to "+", re-captured, re-inspected PASS.
